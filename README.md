# Baker’s World Adventure 🌍

A colorful, gentle geography game for young explorers. Click continents, listen to clues, collect stars, and earn six adventure badges.

## Play

Open `index.html` in a web browser. No installation or build step is needed.

## Adventures

1. **Color explorer** — match colorful continents.
2. **Animal adventurer** — find animals’ home continents.
3. **World whiz** — recognize continent shapes.
4. **Landmark lookout** — discover famous places.
5. **Nature detective** — solve geography clues.
6. **Super explorer** — explore a map without colors or labels.

Each adventure has five challenges. All levels are available from the start, with hints, encouraging feedback, spoken prompts, and no timers or penalties. Free exploration lets children hear continent names and animal facts.

## For families

- Use the speaker button to replay clues; speech support and voices vary by browser and device.
- Stars and badges are saved only in the current browser when local storage is available. Progress does not sync between devices.
- The world map is simplified for play. Animals are examples, not an exhaustive account of where they live.
- Google Fonts is used for typography, with built-in fallback fonts if unavailable.

## Hosting on GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Files

- `index.html`: page structure
- `style.css`: responsive styling
- `app.js`: map, challenges, audio, and local progress

Plain HTML, CSS, and JavaScript. No dependencies, accounts, API keys, or server are required to play.
